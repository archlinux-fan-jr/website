How to connect on Java

  1. Open Minecraft Java Edition and click Multiplayer.
  2. Click Add Server and enter any name, like Kris SMP.
  3. Paste the server IP into the Server Address box.
  4. Click Done, select the server, and press Join Server.

How to connect on Bedrock

  1. Open Minecraft Bedrock Edition, click Play, then open the Servers tab.
  2. Scroll down and click Add Server, then enter any name, like Kris SMP.
  3. Enter the server IP and set the port to NO
  4. Click Save, select the server, and join.
